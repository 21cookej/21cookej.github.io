Build a signal world

Choose a block from the hotbar and drag to build. Use Direction or R before placing; the hotbar previews turn to match. Click a placed block of the selected type to rotate it 90°, or use Inspect to edit its direction. Inspect a block to edit its own settings. Select a rectangle to copy, delete, or apply the current settings to matching block types.

Every step reads the previous tick, then updates all blocks together. Arrow, gates and delay blocks accept signals from their back and sides. Sources emit in their configured directions. Jump blocks land at the chosen distance.

Displays: edge-connected lamps with the same display group share any external input in one tick. Different groups stay separate. Turn off “Join display” for an independent pixel. Lamps never feed signals back into circuits.

Lens: passes incoming signals forward in its selected RGB color. Powered arrows and lamps show the exact signal color; other blocks keep their material color.

Links: the small numbered badge identifies the wireless channel. Enable Link connection lines to see each channel’s network in its badge color. Lines are visual only; matching channels share received signals. A link does not receive from another link, preventing wireless self-feedback. Use different channels for independent circuits.

Timing: delay is additional ticks after the normal one-tick propagation. Pulses use period, on-time and phase. Copy/paste copies block configuration; simulation state starts fresh.

Processing budget: enable Dedicated CPU worker, set CPU budget to 100%, and use Maximum speed for maximum actual throughput. A display rate of 5 or 15 updates/s reduces transfer overhead while still rendering the full board. The worker can occupy one CPU core. Its readout shows computed ticks/s; target rates are not guaranteed. Edits restart from the most recently displayed tick.

Fast-forward: use ticks, seconds, minutes, hours, days, years or centuries. One tick represents one simulated second for these duration controls; a year is 365.25 days. Exact repeated states allow whole-cycle skipping. Circuits that do not repeat are computed in short batches and may take longer. Stop cancels at the current tick. Maximum speed is hardware-dependent. Rendering is throttled separately and the full board remains drawn.

Canvas: new boards start at 112 × 88. Demos allocate sufficient space and frame their content automatically. Fit circuit returns to the overview; Zoom and Shift + middle drag let you inspect the wiring.

Little Man CPU demo: a compact 10 × 10 grid of Input memory cells, physical clock phases, Store registers, text-splitting Math, Compare decoders and data paths. It supports INP, OUT, LDA, STA, ADD, SUB, BRA, BRZ, BRP and HLT. The upper-right joined button starts execution. The lower upper-right button loads the next Program line into the next address. Bottom panels are user Input, Program and Output. Reload the demo to start again.

Line-by-line Input: choose One line per trigger. Each trigger sends the next whole line; Loop lines repeats at the end. Clear information after sending removes the sent line. Text subtraction with Split text into command / operand sends the first word forward and the remaining operand to its clockwise side; SLT 4 becomes SLT and the number 4.

Board resize preserves blocks inside the new bounds. Undo restores edits and resizing. Project imports are validated before replacing the board.

Information: A wired Button triggers an Input panel to release its complete contents. Arrows and splitters carry/copy it intact. Output panels display it. Enable Moving information to see tiny text boxes on powered paths. Input panels can retain or clear contents after sending, and optionally store arriving information.

Math: accepts its back and sides; the arrow tip is output. Use adjacent counter counts, carried information, or Automatic. A front counter receives the calculated amount added to its stored count. Source counters can reset after use. Without an output counter, the result travels on one tick. Information inputs can wait for a partner or pair within an arrival window; unmatched timed inputs pass through. Add joins text/lists; Multiply repeats text/lists by a count or discards them. No 8-bit arithmetic limit.

Compare: Accepts two carried values, or reads adjacent counter/Store values. It compares text, numbers and lists; ordinary pulses are compared by their complete duration after falling low. Matching values emit your configured number, text or JSON on one tick, in the selected color. Each first value waits for its partner. Store remembers complete information; a trigger reads it back out. Counter IDs remain an optional legacy mode.
